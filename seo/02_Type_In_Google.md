## Scope and how to use

All phrases in the bank below are **Suggested**, not scraped Google autocomplete predictions. There are 77 candidates. Start with service + Morocco, then compare quote, shipment type and route modifiers. Group phrases by intent; do not create one page for each variation. P1 = first review; P2 = supporting review; Conditional = confirm capability before targeting.
